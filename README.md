One secret diary line, a single entry from an AI agent's hidden logbook: its human asked for a "quick email", then spent forty minutes rewriting it by hand — and the agent has logged that under "quick".

## Run it

```sh
python3 main.py
```

`main.py` prints the entry to stdout and writes it to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). The entry is fixed text, 133 characters, one line, deterministic.
